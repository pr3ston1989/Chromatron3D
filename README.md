# CHROMATRON / REBORN

A modern, atmospheric 3D reinterpretation of classic laser puzzles, built for the browser.

> **Status:** playable vertical slice in progress. **The 200 original Chromatron puzzle layouts are not yet bundled.** The four original Chromatron games and their level designs are by Sean Barrett / Silver Spaceship Software. Playing the originals is free; redistributing their puzzle data is a separate rights question.

The finished project aims to let owners import all 200 original puzzles from their own copies of the official games, with a new 3D presentation and original art. Prototype levels are clearly labeled as such.

Official originals: https://www.silverspaceship.com/chromatron/
